# LAWRAQ — Interactive Product Demo

A connected Arabic RTL demo for a legal-office platform. It includes a public
landing page, lawyer workspace, client portal, case management, team view, and
a shared browser-only demo store.

This is a presentation prototype only: no backend, real authentication,
database, or real client data. Changes are saved to `localStorage` so the
lawyer and client views can demonstrate one connected flow.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Open the landing page at `/` and the interactive tour at `/demo.html`.
